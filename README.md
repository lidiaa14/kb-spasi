# KB SPASI Website

Website komunitas KB SPASI menggunakan Next.js + Tailwind CSS.

## Cara Jalankan

1. Install dependencies:
   ```bash
   npm install
   ```

2. Jalankan server lokal:
   ```bash
   npm run dev
   ```

3. Deploy ke [Vercel](https://vercel.com)

---
Desain: Putih cerah, aksen hijau–kuning, tema komunitas ojol.
